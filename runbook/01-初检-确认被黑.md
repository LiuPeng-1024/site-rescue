# 第 1 章 · 初检：怎么确认被黑了

> 适用：宝塔 + WordPress 站长。目标：10 分钟内确认"是不是中招了、大概什么类型"。

## 典型症状（中一条就往下查）

- 百度/Google 搜自己站名，**快照标题或描述出现赌博、棋牌、色情词**（你自己打开网站完全正常——cloaking，给爬虫看一套给你看一套）
- 排名/收录突然暴跌；主机商发来"恶意内容/外发异常"告警
- 访客说打开你的站报毒、跳转奇怪页面
- 服务器 CPU/内存/带宽无故飙高（挖矿或攻击他人）

## 四步确认

**① site: 自己的域名**

百度和 Google 各搜一次 `site:你的域名`，逐页看标题描述。 cloaking 的马只对爬虫可见，这一步是最快发现途径。

**② 用爬虫视角抓首页**

```bash
curl -s -A "Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)" https://你的域名 | grep -i -E "赌博|棋牌|博彩|彩票|威尼斯|百家乐" | head -5
```

有输出 = 高度疑似 cloaking 挂马。再用普通 UA 抓一次对比，两边内容不同 = 实锤。

**③ 查最近被修改的文件**

```bash
find /www/wwwroot/你的域名 -name "*.php" -mtime -14 -type f | head -30
```

最近 14 天被改过的 PHP 列出来。如果你两周没更新过插件主题，这个列表里不该有太多东西。

**④ 跑扫描器（推荐，代替手动 ②③）**

```bash
curl -o sr-scan.py https://raw.githubusercontent.com/LiuPeng-1024/site-rescue/main/scan/sr-scan.py
python3 sr-scan.py /www/wwwroot/你的域名 --url https://你的域名
```

报告分【高危】【可疑】【提醒】【通过项】。高危有几条就基本坐实，只读不改，放心跑。
