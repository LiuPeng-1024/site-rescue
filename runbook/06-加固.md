# 第 6 章 · 加固：只清理不加固，等于给黑客留门

> 对着攻击路径一条一条堵。每条都附验证方法——**防护不做验证等于没做**。

## 6.1 wp-config 双 DISALLOW（最先做，收益最大）

`wp-config.php` 加两行：

```php
define('DISALLOW_FILE_EDIT', true);
define('DISALLOW_FILE_MODS', true);
```

效果：后台"编辑主题文件""安装插件/主题"全废。攻击者就算拿到管理员密码，也没法通过后台往服务器写 PHP。

## 6.2 REST 用户枚举收口（nginx+PHP 双保险）

`/wp-json/wp/v2/users` 会把用户名白送给爆破者。坑：**nginx 的 location 只看路径，拦不住 `?rest_route=` 写法**，所以必须两层：

PHP 层（主题 functions.php 末尾，真正禁用端点）：

```php
add_filter('rest_endpoints', function ($endpoints) {
    if (!is_user_logged_in()) {
        unset($endpoints['/wp/v2/users'], $endpoints['/wp/v2/users/(?P<id>[\d]+)']);
    }
    return $endpoints;
});
add_action('template_redirect', function () {
    if (!is_user_logged_in() && isset($_GET['author'])) {
        wp_redirect(home_url('/'), 301); exit;
    }
});
```

nginx 层（挡批量扫描器，省 PHP 开销）：

```nginx
location ~ /wp-json/wp/v2/users { return 403; }
```

验证（三种写法都要测）：

```bash
curl -o /dev/null -w "%{http_code}\n" https://你的域名/wp-json/wp/v2/users        # 期望 403/404
curl -o /dev/null -w "%{http_code}\n" "https://你的域名/?rest_route=/wp/v2/users"  # 期望 404
curl -o /dev/null -w "%{http_code}\n" "https://你的域名/?author=1"                 # 期望 301/404
```

## 6.3 xmlrpc 拦截

```nginx
location = /xmlrpc.php { return 403; }
```

## 6.4 安全响应头（nginx）

```nginx
add_header X-Frame-Options SAMEORIGIN;
add_header X-Content-Type-Options nosniff;
add_header Referrer-Policy strict-origin-when-cross-origin;
```

## 6.5 wp-login 限速（防爆破）

```nginx
# http 段
limit_req_zone $binary_remote_addr zone=wplogin:10m rate=5r/m;
# server 段
location = /wp-login.php { limit_req zone=wplogin burst=3 nodelay; }
```

## 6.6 uploads 禁止执行 PHP

```nginx
location ~* /wp-content/uploads/.*\.php$ { return 403; }
```

## 6.7 Cloudflare 层（推荐，挡扫描突发）

免费版即可：自定义规则对扫描路径（`/xmlrpc.php`、`/wp-login.php`、插件目录下的 .php/readme.txt）做托管质询，扫描器过不了 JS 验证。完整表达式和两个必避的坑（别拦插件静态资源、别掐 admin-ajax）见 [CF 部署手册](https://github.com/LiuPeng-1024/site-rescue/blob/main/README.md) 附录。**顺手把安全组收口：80/443 只放行 CF IP 段，直连 IP 的扫描就全失效了。**

## 6.8 插件卫生（最简单也最常犯）

- 不用的插件和主题：**卸载删除，不要改名"禁用"**
- 在用的：全部升到最新
- 来源不明的"破解版"插件：直接删，那是马的重要来源
