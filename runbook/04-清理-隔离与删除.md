# 第 4 章 · 清理：隔离与删除的正确姿势

> 原则：**隔离优先，不直接 rm**。留着证据才能找根因，误删了能还原。

## 清理顺序（按这个来，别乱）

**① 隔离马的文件**

```bash
mkdir -p /www/backup/quarantine-$(date +%Y%m%d)
# 逐个移动到网站目录之外（不是删除）
mv wp-content/languages/zxvsg.php /www/backup/quarantine-$(date +%Y%m%d)/
```

**② 清自动复活机制**（很多马靠这些复活，漏了等于白清）

```bash
crontab -l          # 看有没有陌生定时任务
cat .user.ini 2>/dev/null
cat .htaccess | grep -i -E "eval|base64|auto_prepend" 
```

`auto_prepend_file` 是经典复活手段（每次请求先执行马），在 `.user.ini` 或 `.htaccess` 里。

**③ 改全部密码**：宝塔后台、WordPress 后台、数据库、FTP/SSH。马已经进来过，凭据默认泄露。

**④ 更新一切**：WP 核心、全部插件、全部主题到最新版。**不用的插件和主题直接卸载删除——不是改名"禁用"**（教训见第 5 章）。

**⑤（可选但推荐）重装 WordPress 核心**：后台「仪表盘→更新→重新安装」，或 wp-cli `wp core download --force --skip-content`。只换核心文件，不动你的内容。

## 数据库层面（容易被忽略的两处）

- **隐藏管理员**：后台「用户」里有没有不认识的账号；有就删
- **恶意 option**：`wp_options` 里陌生的大眼睛一看就不对的记录（慎删，拿不准先查）

## 什么时候才算"删"

隔离观察 **3-7 天**，网站功能一切正常、没有复发，quarantine 目录里的东西才能真删。期间任何异常，先怀疑误删，把文件放回去再排查。
