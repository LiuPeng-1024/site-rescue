# 第 7 章 · 复查验证：怎么确定真的干净了

> "没发现问题"不等于"没有问题"。只能保证"已知验证手段下未发现"——所以要多手段、分时间验证。

## 收工检查单（7 项全过才算完）

```bash
# ① 高危文件复查：再跑一遍扫描器，【高危】应为 0
python3 sr-scan.py /www/wwwroot/你的域名 --url https://你的域名

# ② 信息泄露文件（都该 404）
for f in .git/config wp-config.php.bak debug.log backup.sql .env; do
  curl -s -o /dev/null -w "$f -> %{http_code}\n" https://你的域名/$f
done

# ③ xmlrpc（该 403）
curl -s -o /dev/null -w "%{http_code}\n" https://你的域名/xmlrpc.php

# ④ REST 用户枚举三变体（403/404/301）
curl -s -o /dev/null -w "%{http_code}\n" https://你的域名/wp-json/wp/v2/users
curl -s -o /dev/null -w "%{http_code}\n" "https://你的域名/?rest_route=/wp/v2/users"
curl -s -o /dev/null -w "%{http_code}\n" "https://你的域名/?author=1"

# ⑤ uploads PHP 执行（该 403；先放个测试文件再删）
# ⑥ 首页该 200，且自己 UA 和爬虫 UA 内容一致（无 cloaking）
curl -s -A "Mozilla/5.0 (compatible; Googlebot/2.1)" https://你的域名 | grep -i -E "赌博|棋牌|博彩" | head -3

# ⑦ 漏洞插件路径（已删的插件目录该 404）
curl -s -o /dev/null -w "%{http_code}\n" https://你的域名/wp-content/plugins/已删插件目录名/
```

## 复发观察期

- **48 小时内**：每天 `site:你的域名` 一次，看快照有没有异常词；扫一遍扫描器
- **7 天内**：隔天一次同上；观察服务器资源（CPU/内存）有没有莫名飙高
- **复发怎么办**：别慌也别再删一轮了之——回[第 5 章](05-根因定位.md)，门还没找到。重点看隔离区马的访问日志、有没有漏掉的 cron/.user.ini、兄弟站交叉传染

## 长期姿势

- 每周扫一次扫描器（可挂 cron）
- 插件主题保持最新；不用的删
- 数据库密码、后台密码 3-6 个月轮换一次
- 备份：宝塔计划任务，定期异地备份（本地备份会被一锅端）
