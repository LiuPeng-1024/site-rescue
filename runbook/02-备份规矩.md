# 第 2 章 · 备份规矩（动手之前，先读完这页）

> 清理被黑的站，最大的事故不是马，是**误删**。这页只有三条规矩，但都踩过坑。

## 规矩一：站点级备份先有一份

宝塔面板 →「网站」→ 备份站点；「数据库」→ 找到对应库 → 备份。

或命令行：

```bash
cd /www/wwwroot && tar czf /www/backup/site-$(date +%Y%m%d).tar.gz 你的域名
mysqldump -u用户名 -p 数据库名 > /www/backup/db-$(date +%Y%m%d).sql
```

有这一份兜底，后面怎么操作都错不到哪去。

## 规矩二：删任何文件之前，留副本

```bash
mkdir -p /www/backup/quarantine-$(date +%Y%m%d)
cp 可疑文件路径 /www/backup/quarantine-$(date +%Y%m%d)/
```

**是复制留证，不是直接删。** 副本还有两个用处：事后分析马的行为、误删了能放回去。

## 规矩三：怀疑归怀疑，别顺手定罪

真实教训：排查时主题里一个 189KB 的 `index.php` 被列进嫌疑名单（WordPress 主题的 index.php 一般没这么大）。打开一看，整个文件没有一个 `<?php`，全是静态 HTML——不知道什么时候生成的页面快照。因为留了副本的习惯，核实后原样放回，虚惊一场。

**判断不了的文件，先隔离（移动到网站目录外），观察几天，网站正常再处理。** 隔离和删除的区别，在第 4 章细说。
